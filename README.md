# Fish & Serve

Idle-arcade fishing game built with Godot 4 — catch fish, cut them into
steaks, serve the customer line, earn cash, buy upgrades.

Play: https://xatusbetazx17.github.io/fish-and-serve/

Controls: WASD / arrows / gamepad, or drag on the left side of the screen
(floating joystick) on phones.
